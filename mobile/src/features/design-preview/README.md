# Design Preview

الغرض من هذه الوحدة هو توفير معرض تفاعلي لمراجعة اتجاه واجهات School قبل توصيلها ببيانات الخادم.

## الأدوار المعروضة
- ولي الأمر: اختيار ابن، مشاهدة ملخصه، ومعاينة حالة عدم وجود أبناء.
- المعلم: اختيار شعبة، مشاهدة عينة طلاب الشعبة، ومعاينة عدم وجود إسنادات.
- الطالب: لوحة يومية مبسطة بجدول الحصص والواجبات والاختصارات.

## ضوابط البيانات
كل الأسماء والأعداد والنتائج في هذه الوحدة تجريبية وثابتة داخل data.ts. لا يجوز استخدام هذه البيانات خارج المعاينة أو تضمينها في الشاشات المتصلة بالخادم.

## التفاعلات
- اختيار الدور يبدل لوحة المعاينة.
- اختيار الابن يغير الملخص الظاهر.
- اختيار الشعبة يغير الطلاب الظاهرين.
- مفتاح حالة البيانات يعرض حالات الفراغ.
- الاختصارات والإشعارات تعرض رسالة توضح أنها معاينة فقط وليست وظائف متصلة.

## اعتماد التصميم
التصميم يستند إلى المرجع البصري الموثق في docs/mobile/02-نظام-التصميم-والمرجع-البصري.md. يجب أخذ لقطات من Android وقياسها مقابل المرجع قبل اعتماد الشاشات للإنتاج.
