# Feature modules

كل مجلد يمثل وحدة مستقلة. عند تنفيذ الوحدة تنشأ الملفات اللازمة داخل api وcomponents وhooks وscreens وschemas وtypes وindex.ts.

- auth: التسجيل والدخول والتحقق والجلسات.
- schools: اختيار المدرسة والسياق.
- profiles: الملفات والأدوار وتبديل مساحة العمل.
- students: الطالب وبياناته الأكاديمية.
- guardians: ولي الأمر والأبناء.
- teachers: المعلم والشعب والإسنادات.
- attendance: الحضور والغياب والأعذار.
- timetable: الجداول والحصص.
- homework: الواجبات والتسليمات.
- assessments: الاختبارات والتقييمات.
- fees: الرسوم والفواتير والتحصيل.
- notifications: مركز الإشعارات.
- conversations: المحادثات والمرفقات.
- employee: الخدمات الوظيفية.
- settings: إعدادات المستخدم والمظهر.
