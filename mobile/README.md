# School Mobile

عميل الهاتف الموحد لمنصة School باستخدام Expo + React Native + TypeScript.

## المتطلبات والتشغيل

من داخل مجلد mobile:

~~~bash
npm install
cp .env.example .env
~~~

تأكد من أن EXPO_PUBLIC_API_BASE_URL يشير إلى API الفعلي وينتهي بـ /api/v1، ثم:

~~~bash
npx expo install --check
npm run typecheck
npx expo start
~~~

تشغيل Android:

~~~bash
npm run android
~~~

Development Build بعد ربط حساب EAS وإعداد projectId وبيانات المنصة:

~~~bash
npx eas-cli login
npx eas-cli init
npx eas-cli build --profile development --platform android
~~~

## ما هو موجود في التطبيق

### الحساب والمدرسة
- الدخول برقم الهاتف وكلمة المرور.
- التسجيل وتأكيد رقم الهاتف عبر OTP.
- استعادة كلمة المرور.
- تخزين جلسة الجهاز في SecureStore وتجديد access token.
- تحميل المدارس واختيار المدرسة والملف/الدور.
- قبول دعوات المدرسة.
- عزل بيانات الاستعلام حسب الحساب والجلسة والمدرسة.

### الوظائف الأكاديمية
- صفحة الدراسة والتقييم الحالية /academics تعرض الواجبات والدرجات حسب الدور.
- الطالب يرسل تسليم الواجب، والمعلم يصحح أو يطلب إعادة التسليم، وولي الأمر يرى بيانات الأبناء ضمن حدود API.
- صفحة /exams لأداء الاختبارات الإلكترونية المنشورة للطالب. يجلب التطبيق ورقة الأسئلة الآمنة ويُرسل الإجابات النهائية للخادم؛ لا يحتسب الدرجات محلياً.

### الحضور والغياب
- ولي الأمر يعرض سجلات حضور أبنائه ودرجات المواظبة وطلبات الأعذار.
- المعلم يختار الشعبة المسندة، ويفتح سجل اليوم، ويستخدم حالات الحضور المعرفة في المدرسة، ويحفظ السجل ثم يرسله للمراجعة.
- الحالات الافتراضية والأعذار المعتمدة تُحمّل من سجل الخادم.
- لا تعرض النسخة الحالية سجل حضور ذاتياً للطالب لعدم وجود API مناسب لذلك في العقد الحالي.

### الرسوم والمراسلات
- /fees: كشف حساب الطالب، الفواتير، الأقساط، سندات القبض، حركات الرصيد الدائن، أعمار المتأخرات ومطابقة رصيد الحساب مع دفتر الأستاذ.
- /messages: قائمة المحادثات المصرح بها، الرسائل النصية، تحديث دوري، تعليم المحادثة كمقروءة وكتمها.
- لا ينشئ التطبيق محادثة مع مستخدم عشوائي؛ إنشاء المحادثات يحتاج مشاركين مصرحاً بهم من الخادم.

### الإشعارات
- /notifications: الإشعارات داخل النظام، تعليم إشعار واحد أو الكل كمقروء.
- تفضيلات قنوات الإشعار التي سبق أن سجلها المستخدم أو المدرسة.
- تسجيل أجهزة Push متاح في API، لكن خدمة إرسال Push الخلفية وإعداد EAS/Firebase/APNs لم تكتمل؛ لذلك لا يُعلن التطبيق أن Push الفعلي يعمل الآن.

## حدود التنفيذ الحالية
- لا يزال يلزم اختبار الرحلات بحسابات فعلية لأدوار طالب/ولي أمر/معلم من نفس المدرسة.
- لم يتم بعد بناء APK أو تجربته على جهاز Android حقيقي.
- حفظ إجابات الاختبار في النسخة الحالية يتم عند التسليم النهائي فقط، وليس على الخادم أثناء الكتابة.
- المحادثات في النسخة الحالية نصية؛ المرفقات والتنقل بين دفعات الرسائل الأقدم/الأحدث يحتاجان استكمال الواجهة.
- الحضور الذاتي للطالب يحتاج API مخصصاً.
- إرسال إشعارات Push يحتاج خدمة خلفية وإعداد مزود المنصة.
- لا تضع ملفات .env الحقيقية أو أسرار SMS/Push في المستودع.
- لا تنفذ مدفوعات أو إنشاء سندات مالية أو اعتماد حضور/درجات خارج إجراءات API الرسمية.
- لا تدمج الفرع في main إلا بموافقة صاحب المشروع.
