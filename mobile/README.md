# School Mobile

عميل الهاتف الموحد لمنصة School باستخدام Expo + React Native + TypeScript.

## المتطلبات
- Node.js 22.13 أو أحدث.
- npm.
- Android Studio أو جهاز Android للاختبار.
- حساب Expo/EAS عند البدء بالبناء السحابي والنشر.

## التجهيز المحلي

من داخل مجلد mobile:

~~~bash
npm install
cp .env.example .env
~~~

تأكد من أن EXPO_PUBLIC_API_BASE_URL يشير إلى عنوان API الفعلي وينتهي بـ /api/v1، ثم نفذ:

~~~bash
npx expo install --check
npm run typecheck
npx expo start
~~~

لتشغيل Expo على Android:

~~~bash
npm run android
~~~

لإنشاء Development Build بعد ربط حساب EAS:

~~~bash
npx eas-cli login
npx eas-cli init
npx eas-cli build --profile development --platform android
~~~

تثبت إصدارات Expo SDK في package.json. عند إضافة أي حزمة Native تابعة لـ Expo استخدم npx expo install اسم-الحزمة حتى يختار الإصدار المتوافق مع SDK 58، ثم نفذ npx expo install --check.

## المكتبات الأساسية
Expo Router، React Native Paper، Lucide React Native، TanStack Query، Zustand، React Hook Form، Zod، Expo SecureStore، Expo Notifications، Expo SQLite، Expo Font، Expo Localization، EAS Build وEAS Update.

## حالة التطبيق الحالية

### تدفقات متصلة بالخادم
- تسجيل الدخول برقم الهاتف وكلمة المرور مع إنشاء جلسة جهاز.
- إنشاء حساب وتأكيد رقم الهاتف عبر رمز OTP.
- طلب رمز استعادة كلمة المرور وتأكيده وتعيين كلمة مرور جديدة.
- تخزين جلسة الدخول ومعرف الجهاز في Expo SecureStore.
- تجديد access token عند انتهاء صلاحيته أو رفضه، مع إعادة الطلب مرة واحدة.
- تسجيل الخروج وإبطال جلسة الجهاز.
- تحميل المدارس المتاحة واختيار المدرسة الافتراضية أو الاختيار اليدوي.
- قبول دعوة مدرسة باستخدام الرمز الذي أرسلته الإدارة.
- تحميل ملفات الحساب داخل المدرسة واختيار مساحة الطالب أو ولي الأمر أو المعلم أو الموظف أو الإدارة بحسب الدور والملفات التي يعيدها الخادم.
- لوحات أولية حقيقية: ملف الطالب والجدول، أبناء ولي الأمر وجداولهم، إسنادات المعلم والطلاب والجدول، وملف الموظف.

كل بيانات هذه اللوحات تُجلب من API. لا تستخدم وحدات اللوحات بيانات المعاينة الثابتة. عند غياب ملف أو جدول أو إسناد تظهر حالة فارغة، ولا يخترع التطبيق أرقام حضور أو درجات.

### معاينة التصميم
المسار /preview يحتفظ بمعرض التصميم التفاعلي السابق. هذه شاشة منفصلة ببيانات افتراضية هدفها مقارنة الشكل فقط، ولا تستخدم كواجهة تشغيل حقيقية ولا تتصل بالخادم.

## ضوابط الأمان والعزل
- لا تضع أسراراً أو ملفات .env الحقيقية في المستودع.
- لا تحفظ access token في AsyncStorage أو Zustand؛ يستخدم SecureStore.
- يرسل العميل X-School-ID في طلبات المدرسة.
- مفاتيح TanStack Query مرتبطة بالحساب والجلسة والمدرسة والدور، وتمسح الذاكرة المؤقتة عند تسجيل الخروج أو تبديل المدرسة/الدور.
- لا يقبل التطبيق school_id أو student_id دليلاً على الصلاحية؛ الخادم هو مصدر الحقيقة.
- لا ينشئ طلب ربط ولي أمر بطفل من دون API آمن واعتماد المدرسة.
- لا يدمج هذا الفرع في main إلا بموافقة صاحب المشروع.
