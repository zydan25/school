# مواصفات شاشات تطبيق School Mobile

**المرجع البصري:** التصورات التي ظهرت في محادثة 3 نوفمبر 2026 لشاشات الطالب وولي الأمر والمعلم.

## 1. قواعد مشتركة
- واجهة عربية RTL؛ النصوص والأرقام والتواريخ تعرض باتساق.
- اسم المدرسة وشعارها يظهران في سياق المدرسة النشطة.
- الهيدر يحتوي على اسم المدرسة وزر الإشعارات وملف المستخدم.
- نستخدم بطاقات قصيرة وأيقونات واضحة بدلاً من قوائم طويلة.
- لكل شاشة حالات تحميل وفراغ وخطأ ونجاح.
- البيانات خاصة بالمدرسة والملف المحددين.
- يوجد وصول ثابت لتبديل المدرسة والملف والحساب.
- لا تظهر بيانات وهمية في إصدار الإنتاج.

## 2. لوحة الطالب
- بطاقة ترحيب بالطالب والصف والشعبة.
- ملخص اليوم: الحصص والواجبات والحضور.
- اختصارات إلى الجدول والواجبات والاختبارات والدرجات.
- قائمة الحصص القادمة، ويظهر الوقت والمادة والمعلم والقاعة.
- رسالة تشجيعية بسيطة لا تشتت الطالب.
- التبويبات النهائية: الرئيسية، دراستي، الإشعارات، حسابي.

## 3. لوحة ولي الأمر
- الأبناء هم المحور البصري.
- يظهر كل ابن في بطاقة قابلة للاختيار، تتضمن الصورة أو Avatar والاسم والصف والشعبة.
- يتغير ملخص الحضور والواجبات والرسوم عند اختيار الابن.
- زر إضافة/ربط ابن لا ينشئ العلاقة محلياً؛ يقود مستقبلاً إلى مسار طلب موثوق أو إجراء الإدارة بعد توفر عقد الربط.
- الوظائف: الحضور والغياب، الأعذار، الانصراف المبكر، الواجبات، الدرجات المنشورة، الجدول، الرسوم، الشكاوى، البلاغات، الاستدعاءات، الرسائل والإعلانات.
- عند عدم وجود أبناء تظهر Empty State واضحة لا تعرض بيانات افتراضية.

## 4. لوحة المعلم
- ملخص عدد الطلاب والشعب والحصص لهذا اليوم.
- بطاقات الشعب المسندة للمعلم فقط، تعرض الصف والشعبة والمادة وعدد الطلاب.
- اختيار بطاقة الشعبة يفتح شبكة طلابها.
- إجراءات الشعبة: رصد الحضور، إضافة واجب، إدخال الدرجات، جدول الحصص.
- عند غياب الإسنادات تظهر رسالة مفهومة ولا تظهر قائمة عامة لطلاب المدرسة.
- التبويبات النهائية: الرئيسية، شُعبي، الإشعارات، حسابي.

## 5. حالات المعاينة
معرض التصميم يدعم تفعيل حالة عدم وجود ملفات لولي الأمر أو عدم وجود إسنادات للمعلم، حتى يمكن مراجعة حالات الفراغ قبل تطوير الوظائف المتصلة.

## 6. اعتماد المعاينة
التفاعلات المتاحة في المعرض تخص تغيير الدور والابن والشعبة وحالة الفراغ فقط. اختصارات الخدمات تعرض رسالة تعريفية صريحة بأنها معاينة وليست وظائف متصلة بالخادم.
