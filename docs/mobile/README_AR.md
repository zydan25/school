# تطبيق School Mobile — فهرس مرجع الهاتف

هذا هو المرجع المعتمد لتطبيق الهاتف الموحد المبني باستخدام Expo + React Native. التطبيق عميل مستقل داخل مستودع School، ولا يستبدل Django أو يكرر قواعد الأعمال أو قاعدة البيانات.

## الوثائق
- 00-القرار-المعماري.md: المكدس التقني، بنية المجلدات، حدود الوحدات وإدارة الحالة.
- 01-مواصفات-الشاشات.md: شاشات الطالب وولي الأمر والمعلم والموظف والإدارة.
- 02-نظام-التصميم-والمرجع-البصري.md: الألوان والتخطيط والبطاقات والأيقونات والتصورات المرئية.
- 03-عقد-التكامل.md: ربط الشاشات بعقود API الموجودة والفجوات التي تحتاج عملاً في الخادم.
- 04-تقرير-تنفيذ-معرض-التصميم.md: ما تم تنفيذه في المرحلة الحالية ونتائج الفحص.

## حالة التنفيذ
- الفرع المعتمد للتطوير: feature/mobile-expo-foundation.
- تأسس مجلد mobile/ ومشروع Expo SDK 58.
- أضيف معرض تفاعلي لواجهات الطالب وولي الأمر والمعلم.
- أضيفت مكونات مشتركة للبطاقات والصور الشخصية والأيقونات والإحصائيات والاختصارات وحالات الفراغ والتنبيهات.
- التفاعلات والبيانات الحالية للمعاينة فقط ولا تتصل بالخادم.
- لم تنفذ بعد رحلات المصادقة أو الوظائف الأكاديمية الحقيقية.
- لم يتم ربط مشروع EAS بحساب نشر أو إنشاء معرفات المتاجر.

## قواعد حاكمة
1. لا تنفذ عمليات أعمال أو صلاحيات حساسة محلياً؛ الخادم هو مصدر الحقيقة.
2. لا تنشئ مسارات API مكررة إذا كان المسار الحالي يغطي الوظيفة.
3. لا تربط ملف طالب أو معلم أو ولي أمر بمجرد معرفة رقم أو اسم؛ يلزم تحقق واعتماد موثوق.
4. لا تخلط cache بين المدارس أو الملفات الشخصية.
5. لا تعاود تلقائياً طلبات الإنشاء والتحصيل والعكس بعد timeout.
6. كل شاشة تستخدم مكونات نظام التصميم وحالات التحميل والفراغ والخطأ.
7. لا تدمج هذا الفرع في main إلا عبر مراجعة وطلب دمج وموافقة صاحب المشروع.
